# Purnells Property Maintenance Website

This is a static website for Purnells Property Maintenance, a local property maintenance and building services company.

## Pages
- Home
- Property Maintenance
- Building Services
- Kitchens & Bathrooms
- Carpentry & Joinery
- Painting & Decorating
- Roofing
- Landscaping
- Testimonials
- Get in Touch (with contact form)

## How to Use
Open any HTML file in your browser. All pages are linked with a shared navigation bar. Replace placeholder images and text as needed.

## Customization
- Update `assets/placeholder.jpg` with your own images.
- Edit the HTML files for your own content.
- Adjust `style.css` for branding and colors.

## Deployment
You can deploy this site to any static web host (Netlify, GitHub Pages, etc.).
